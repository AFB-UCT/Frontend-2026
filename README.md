## Descripción breve

  Proyecto de pagina web dirigida a la empresa EcoRuta Temuco, dirigida por el equipo de desarrollo Kiro™ 2026.
  **EcoRuta Temuco** es una plataforma web que conecta rutas al aire libre de Temuco y Padre Las Casas con emprendedores locales. Su objetivo es que las personas   descubran lugares para recorrer y puedan contactar directamente a quienes ofrecen servicios en la zona, impulsando el turismo y el comercio local.
